# Project Promotions

Hệ thống quản lý voucher / khuyến mãi được xây dựng bằng ASP.NET Core MVC.

## Chức năng chính
- Tạo voucher
- Sửa voucher
- Xóa voucher
- Quản lý số lượng voucher
- Tự động tính trạng thái hoạt động / hết hạn
- Tìm kiếm voucher theo tên / mã
- Lọc voucher theo trạng thái hoạt động

## Công nghệ sử dụng
- ASP.NET Core MVC
- ABP Framework
- SQL Server
- JavaScript / jQuery
- Bootstrap

## Hướng dẫn chạy project
1. Clone repository
2. Restore database
3. Chạy migration/update database
4. Start project ngocyen.Web.Mvc
